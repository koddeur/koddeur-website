For more than ten years, everything has gone through this "Documents" folder. It isn't sophisticated: a few simple rules, applied consistently.

## One folder per area of life

I don't sort my files by format. I sort them by subject in my life. Each top-level folder corresponds to a question someone might ask me: "Your latest payslip?", "Your vehicle registration?", "Your diploma?" I always know where to look because I start from the question.

My folders fall into six families:

| Family | My folders | What I put in them |
| --- | --- | --- |
| Identity and official | Documents personnels officiels, Visa Étranger, Diplômes, Photos identités | ID card, passport, driver's license, visas, diplomas |
| Work and career | Travail, CV + Lettres Motivations, Vie Universitaire, Auto-Entreprise, Bafa | Contracts, payslips, CVs by year, university documents |
| Money and administration | Impôts, Banque, Factures, CAF, Patrimoine, Amendes | Tax returns, tax notices, bank details (RIB), invoices |
| Daily life | Santé, Logement, Véhicules | Certificates, proofs of address, papers for each vehicle |
| Leisure | Voyages, Événements, Anniversaires | Tickets, boarding passes, travel insurance |
| Miscellaneous | Autres Documents | Anything that hasn't found its place yet |

I create a top-level folder as soon as a new subject appears in my life, even if it only holds one file. Quitting my permanent job, registering with France Travail, applying for visas to Asia: each of those steps had its own folder.

## My four filing rules

Within each area, I go from general to specific, and I stop at four levels of folders.

Each level answers a more precise question: what are we talking about, which subject, which year or object, which step.

**1. Four levels, no more.** Area, subject, year or object, then step or month. That's deep enough for each folder to stay readable and shallow enough that I never get lost in the tree.

**2. One folder per year for anything recurring.** Taxes, CVs, proofs of address: as soon as a document is renewed every year, it gets a `2024`, `2025`, or `2026` subfolder. For proofs of address, I go down to the month, with names like `2020-07 Juillet`. The number keeps the order, and the month name is readable at a glance.

**3. One folder per object, split by step.** Each vehicle has its own folder, with a subfolder for each stage of its life: purchase, registration certificate, insurance, technical inspection, repairs, sale, and transfer certificate. On the day I sell, everything the buyer needs is in one place.

**4. The date in the file name.** The folder says what the file is about, and the name says when. I write the date as year, month, day, as in `photos_identites_2025_10_31`. Alphabetical sorting becomes chronological sorting.

## Two safety valves to keep the rest tidy

A system that's too strict ends up abandoned, so I've set aside two places for things that don't fit the boxes.

- **An "Archives" folder where versions pile up.** When I renew a license or an ID document, the old version goes into `Archives` or a dated subfolder. The current document stays alone at the top level.
- **An "Autres Documents" folder at the root.** When I don't yet know where a file belongs, it lands there instead of on the desktop. I reclassify it once its subject is clear, or when it's time for a new top-level folder.

## If you want to copy the system

You can take my method as is. Five rules are enough, and you can start with three folders.

1. Sort by area of life (work, health, housing, identity), never by file type.
2. As soon as a document recurs every year, create a subfolder for each year.
3. Give each important object (a car, a home, a contract) its own folder, and split it by step.
4. Put the date at the beginning or end of the file name, in the format `2026-10-24`.
5. Rename the file when you file it, not "later." Later, it's `IMG_7384.HEIC` forever.

That's it. No software, no color labels: just well-named folders and ten years of paperwork I can find from the other side of the world.

## The prompt to organize your folder like mine

If you use an AI assistant that has access to your files, copy this prompt and give it your documents folder. It will create the whole structure, including the still-empty folders, then sort and rename what you already have.

```
You are going to organize my folder of administrative and personal documents using a specific method. Before moving or renaming anything, show me the complete plan and wait for my approval. Do not delete any file.

1. First, create the essential top-level folders, even if they remain empty for now:
- Documents personnels officiels (subfolders: Carte d'identité, Passeport, Permis, Signature)
- Photos identités
- Diplômes
- Visa Étranger
- Travail (one subfolder per employer)
- CV + Lettres Motivations (one subfolder per year)
- Vie Universitaire
- Impôts (one subfolder per year)
- Banque (one subfolder per bank, with an RIB subfolder)
- Factures
- Santé (subfolders: Sécurité sociale, Mutuelle, Carte Vitale, Ordonnances, Vaccins, Spécialistes)
- Logement (subfolders: Bail, Justificatif Domicile by year, Charges)
- Véhicules (one subfolder per vehicle)
- Voyages (one subfolder per destination)
- Événements
- Autres Documents

2. Follow these rules from here on:
- Sort by area of life, never by file type.
- No more than four levels of folders: area, subject, year or object, step or month.
- Any document that recurs every year goes into a subfolder per year (2025, 2026...). For a monthly breakdown, name the folder in the format "2026-07 Juillet".
- Each important object (vehicle, home, contract) gets its own folder, split by step: purchase, insurance, registration certificate, technical inspection, repairs, sale.
- When a document is renewed, the old version goes into an "Archives" subfolder.
- Create a new top-level folder if one of my life subjects doesn't fit any family.

3. Then sort my existing files into this structure.

4. Rename each file using the format: document-type_detail_YYYY-MM-DD.extension (example: tax-notice_income-2025_2026-08-12.pdf). Use the date on the document when it's readable, otherwise the file's date. Prioritize renaming raw names like IMG_1234.HEIC or "Screenshot".

5. If you don't know where a file belongs, put it in Autres Documents and list it for me at the end.

6. Finish with a summary: folders created, files moved, files renamed, files left in Autres Documents.
```

One last point, the most important one: this prompt only sets up the structure. The system only works if you're consistent. Each time you receive a document, add it to the right folder straight away and rename it in the right format. A file left in Downloads "for later" is the start of disorder.
