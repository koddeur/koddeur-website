## Content comes before decoration

A useful interface gives space to the main task. For a technical blog, that means: a clear reading hierarchy, metadata close to the title, and contrast that holds up during a long session.

## Three practical rules

- Reserve strong color for actions and links.
- Keep interactive elements recognizable without hover.
- Use whitespace and vertical rhythm as structuring tools.

```ts
const rule = "if it isn't useful, remove it";
```

Minimalism isn't the absence of choices: it's the result of precise ones.
